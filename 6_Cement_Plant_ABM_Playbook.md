## **VALUE PROPOSITION FRAMEWORK (Per Model)**

### **MODEL 1: CAPEX (Self-Owned)**
| Parameter | Detail |
|-----------|--------|
| **Investment** | ₹4.5-5.0 Cr/MW |
| **Tariff** | N/A (self-consumption) |
| **Savings** | ₹4.5-5.5 Cr/MW/yr vs grid |
| **Payback** | 3.5-4.2 years |
| **IRR** | 22-25% |
| **Tax Benefits** | Accelerated Depreciation (40% yr1), GST Input, Sec 80IA |
| **Risk** | Plant owns O&M, performance |
| **Best For** | Strong balance sheet, tax appetite, long-term horizon |

### **MODEL 2: RESCO (PPA - Zero Capex)**
| Parameter | Detail |
|-----------|--------|
| **Investment** | ₹0 (Shubham invests) |
| **Tariff** | ₹2.80-3.20/kWh fixed 25yr |
| **Savings** | 55-65% vs grid from Day 1 |
| **Payback** | Immediate (OpEx only) |
| **Off-Balance Sheet** | Yes (lease accounting) |
| **Tax Benefits** | GST input on PPA payments |
| **Risk** | Shubham owns performance/O&M |
| **Best For** | Capex-constrained, want OPEX simplicity |

### **MODEL 3: GROUP CAPTIVE (26% Equity)**
| Parameter | Detail |
|-----------|--------|
| **Investment** | 26% equity (~₹1.2 Cr/MW) |
| **Tariff** | ₹2.50-2.80/kWh (lowest) |
| **Savings** | 60-70% vs grid |
| **Cross-Subsidy Surcharge** | Avoided |
| **Additional** | Renewable Energy Certificates (REC) revenue |
| **Compliance** | 51% captive consumption, 26% equity |
| **Best For** | >1MW, want maximum savings, can take equity |

## **OBJECTION HANDLING MATRIX**

| Objection | Root Cause | Response | Proof Point |
|-----------|------------|----------|-------------|
| **"Grid power is reliable enough"** | Complacency | "Grid tariff rising 5-6%/yr. Solar locks 25yr price. Recent 12hr outage at [Peer Plant] cost ₹[X]Cr." | Grid outage data, tariff trend chart |
| **"Capex not approved this year"** | Budget cycle | "RESCO model = Zero capex. OPEX budget item. Or Group Captive = 26% equity (capex-lite)." | Financial model comparison |
| **"Land not available"** | Space constraint | "Ground-mount on waste land / floating on reservoir / carport / nearby land lease (we find)." | Land bank options, drone survey |
| **"DISCOM won't allow open access"** | Regulatory fear | "Rajasthan Open Access Regulations 2022: 1MW+ eligible. We handle all approvals. 50+ approvals done." | AVVNL approval letters |
| **"Existing vendor relationship"** | Incumbency | "We complement - not replace. Specialize in solar EPC + subsidy + captive structuring. Co-exist with your EPC vendor." | Partnership examples |
| **"Technology risk - new inverters/storage"** | Tech conservatism | "Tier-1 only (Sungrow/Growatt/SMA). 10yr inverter warranty, 25yr panel. 2000+ installs, 99.9% uptime." | O&M data, warranty docs |
| **"Need board approval - long process"** | Governance | "We provide board-ready deck: 1-pager, financial model, risk matrix, peer references. 2-week turnaround." | Board deck template |
