## 3. ELIGIBILITY CRITERIA (AVVNL - Similar for JVVNL)

### Mandatory Requirements
| Requirement | Details | Proof Required |
|-------------|---------|----------------|
| **Company Registration** | Pvt Ltd/LLP in Rajasthan (not branch) | COI, MOA/AOA |
| **GST Registration** | Rajasthan GSTIN (08xxxxxxxxx) | GST Certificate |
| **PAN** | Company PAN | PAN Card |
| **Electrical Contractor License** | Class A/Super Class (Rajasthan) | License Copy |
| **MNRE Channel Partner** | Registered with MNRE (if available) | Registration Certificate |
| **Technical Staff** | Min 1 B.Tech Electrical + 2 Diploma/ITI Electrician | Degree/Diploma + Experience Certificates |
| **Past Experience** | Min 3 completed projects (similar capacity) | Completion Certificates + Client References |
| **Financial Capability** | Net Worth ≥ 25% of applied capacity cost | CA Certified Net Worth Certificate |
| **Bank Solvency** | Solvency Certificate ≥ Project Value | Bank Certificate (not older than 6 months) |
| **Tools & Equipment** | Owned/Leased (testing, installation, safety) | Purchase Invoices/Lease Agreements |
| **ISO Certifications** | ISO 9001/14001/45001 (Preferred, not mandatory) | Certificates |
| **Office in Rajasthan** | Physical office with staff | Rent Agreement + Electricity Bill |

## 4. APPLICATION PROCESS - STEP BY STEP

### Phase 1: Document Preparation (Week 1-2)

#### Company Documents
- [ ] Certificate of Incorporation (COI)
- [ ] MOA & AOA (with Solar/EPC in Object Clause)
- [ ] PAN Card of Company
- [ ] GST Registration Certificate (Rajasthan)
- [ ] Board Resolution authorizing empanelment application
- [ ] Power of Attorney for Authorized Signatory
- [ ] Authorized Signatory: PAN, Aadhaar, Photo, DSC Class 3

#### Technical Documents
- [ ] Electrical Contractor License (Class A/Super) - **CRITICAL**
- [ ] MNRE Channel Partner Registration (if applicable)
- [ ] Organization Chart with Technical Staff details
- [ ] CVs of Key Technical Personnel:
  - Project Manager (B.Tech Electrical, 5+ yrs)
  - Site Engineers (Diploma Electrical, 3+ yrs) x 2
  - Safety Officer (Diploma + Safety Certification)
  - Quality Engineer (B.Tech/Diploma, 2+ yrs)
- [ ] List of Tools & Equipment (with invoices):
  - Earth tester, Megger, Clamp meter, Multimeter
  - Torque wrenches, Crimping tools, Cable cutters
  - Safety equipment (PPE, Fall protection, Fire extinguishers)
  - Drone for survey (owned/leased)
  - Vehicle for site transport

#### Financial Documents
- [ ] Audited Financial Statements (Last 3 years) - if new company: CA projected financials
- [ ] CA Certified Net Worth Certificate (Format: DISCOM prescribed)
- [ ] Bank Solvency Certificate (Format: DISCOM prescribed)
- [ ] Income Tax Returns (Last 3 years)
- [ ] GST Returns (Last 12 months - GSTR-1/3B)
- [ ] Bank Statements (Last 12 months - Current Account)

#### Experience Documents
- [ ] **Project Completion Certificates** (Min 3 projects):
  - Client name, capacity, location, date of commissioning
  - DISCOM/SE signature preferred
  - Photos of completed installation
- [ ] **Work Orders/LOAs** for ongoing projects
- [ ] **Client Reference Letters** (3-5 clients)
- [ ] **Performance Certificates** (if any from DISCOMs)

#### Office & Infrastructure
- [ ] Rent Agreement (Notarized) + NOC from Owner
- [ ] Electricity Bill (Office) - not older than 3 months
- [ ] Office Photos (Internal/External + Signage)
- [ ] Warehouse/Storage facility details (if separate)

### Phase 2: Online Application (Week 2-3)

#### AVVNL Portal
- **URL**: https://avvnl.com/empanelment (or https://energy.rajasthan.gov.in/avvnl)
- **Login**: New Registration → Company Registration
- **Form**: Vendor Empanelment Application Form

#### JVVNL Portal
- **URL**: https://jvvnl.org/empanelment (or https://energy.rajasthan.gov.in/jvvnl)
- **Process**: Similar to AVVNL

#### Common Fields to Fill
```
1. Company Basic Details (Name, CIN, PAN, GSTIN, Address)
2. Authorized Signatory Details
3. Category Applied (Class A/Super)
4. Technical Capability (Staff, Equipment, License)
5. Financial Capability (Net Worth, Turnover, Solvency)
6. Past Experience (Project-wise details)
7. Office Infrastructure (Rajasthan locations)
8. Declarations & Undertakings
9. Document Upload (All above in PDF, max 2MB each)
10. Application Fee Payment (Online)
```

### Phase 3: Application Fee

| DISCOM | Category | Fee (Approx) | Payment Mode |
|--------|----------|--------------|--------------|
| **AVVNL** | Class A/Super | ₹10,000 - ₹25,000 | Online (Net Banking/UPI) |
| **JVVNL** | Class A/Super | ₹10,000 - ₹25,000 | Online (Net Banking/UPI) |

*Exact fee on portal at time of application*

### Phase 4: Document Verification (Week 3-6)

#### DISCOM Process
1. **Scrutiny** (7-10 days): Document completeness check
2. **Query/Deficiency** (if any): 7 days to respond
3. **Technical Evaluation** (15-21 days): SE Office review
4. **Site/Office Inspection** (7-14 days): Physical verification
5. **Committee Approval** (7-10 days): Empanelment Committee
6. **Order Issuance** (3-5 days): Empanelment Order + Vendor Code

#### Inspection Checklist (Prepare For)
- [ ] Office premises (signage, staff, records)
- [ ] Technical staff availability (meet key personnel)
- [ ] Tools & equipment (physical verification)
- [ ] Safety equipment & procedures
- [ ] Quality management system (documents)
- [ ] Past project sites (may visit 1-2)

### Phase 5: Empanelment Order (Week 6-10)

#### Deliverables
- **Empanelment Order** (PDF with validity - typically 3 years)
- **Vendor Code** (Unique ID for all DISCOM transactions)
- **Empanelment Certificate** (For client submissions)
- **Terms & Conditions** (Must sign & return)

#### Post-Empanelment
- [ ] Submit signed acceptance within 15 days
- [ ] Update website/marketing with "AVVNL/JVVNL Empaneled"
- [ ] Register on PM Surya Ghar Portal with Vendor Code
- [ ] Register on PM-KUSUM Portal with Vendor Code
- [ ] Inform all BDAs/Sales team

## 6. PM SURYA GHAR & PM-KUSUM VENDOR REGISTRATION

### Prerequisite: DISCOM Empanelment First

### PM Surya Ghar (National Portal)
- **Portal**: https://pmsuryaghar.gov.in
- **Vendor Registration**: "Vendor/Installer Registration"
- **Required**: DISCOM Empanelment Order + Vendor Code
- **Approval**: 7-15 days post DISCOM verification
- **Benefits**: Direct subsidy claim, leads from portal

### PM-KUSUM (Component B - Solar Pumps)
- **Portal**: https://pmkusum.mnre.gov.in
- **State Nodal Agency**: RRECL (Rajasthan Renewable Energy Corporation Ltd)
- **RRECL Portal**: https://rrecl.gov.in
- **Required**: DISCOM Empanelment + RRECL Vendor Registration
- **Process**: RRECL verifies → Adds to approved vendor list → Farmers select from list

### RRECL Vendor Registration
- **Office**: RRECL, 4th Floor, Vidyut Bhawan, Janpath, Jaipur
- **Contact**: 0141-274xxxx | rrecl@rajasthan.gov.in
- **Documents**: Same as DISCOM + Specific RRECL Form
- **Timeline**: 15-30 days

## 9. COMMON REJECTION REASONS & FIXES

| Rejection Reason | Fix |
|------------------|-----|
| Incomplete documents | Use checklist; double-check before submit |
| Electrical Contractor License not Class A | Upgrade license before applying |
| Net worth below threshold | Show projected financials + bank guarantee |
| Insufficient past experience | Partner with empaneled vendor for JV on first projects |
| Office not in Rajasthan | Rent co-working space immediately |
| Technical staff not on payroll | Hire before application; provide EPF proof |
| MOA doesn't mention Solar/EPC | Amend MOA before incorporation (include in objects) |
| GST not Rajasthan-specific | Get Rajasthan GSTIN (08xxxxxxxxx) |
